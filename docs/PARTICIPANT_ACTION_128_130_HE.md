## הגדרת התנהגות129

הוגדר `coach_participant_probe_behavior`, יורש `npc_behavior`. הוא מדווח שהתחיל וממתין; אינו מעניק ציוד או שולח תנועה/תקיפה. הבחירה Verse Behavior הוצגה בבורר המקורי של הנכס. פעולות השליטה לא נתנו תחילה בחירה שנשמרה בקריאה חוזרת; השליטה שוחררה. ניסיון Python ראשון נעצר בבדיקת טיפוס שגויה לפני שינוי, והשני נעצר בבנאי של סוג בסיס מופשט. לא בוצעו force-instantiation, שינוי מסננים או ניסיון ליצור סוג נגזר כדי לעקוף זאת; הסקריפט הכושל הוסר מ־Editor והניסיונות נשמרו בארכיון המקומי.

המשתמש אישר בחירה ושמירה של Verse Behavior והסקריפט. בקריאה מאוחרת הופיע המופע המקורי `CharacterModifier_GuardVerseBehavior_C_0`. השדה הציבורי NPCBehaviorScript קיבל את מחלקת Verse דרך MCP. קריאה חוזרת מחזירה מופע סקריפט בתוך המודיפייר, ולא את נתיב המחלקה שנשלח; בדיקת שוויון מוקדמת ציפתה בטעות לנתיב מחלקה. קריאה ציבורית נפרדת אימתה את המחלקה המדויקת של המופע. הנכס והמפה עברו אימות, הנכס נקי, ובריצה129 נצפה הסקריפט מתחיל בפועל. הבקשה הידנית נפתרה; אין לבקש שוב Type→Participant או בחירת סקריפט.

## תיקון131 ותוצאת הפעולה

בדיקת המקור מצאה שבדיקות השיגור ושינוי הצוות נעשו בתוך `not`. הפעולות מסומנות transacts/decides; כישלון ההקשר עלול לבטל את השינוי.131 החליפה רק את ארבע הקריאות האלה בענפי הצלחה חיוביים עם ספירת הצלחות. לא הוחלפו נקודות, קרקע, התנהגות או נכסים לעומת130; השתנה רק coach_health_probe.verse. גם הערות Epic על [failure contexts](https://dev.epicgames.com/documentation/fortnite/basics-of-writing-code-9-failure-and-control-flow-in-verse) וחתימת [TeleportTo](https://dev.epicgames.com/documentation/fortnite/verse-api/fortnitedotcom/characters/fort_character/teleportto?lang=en-US) תואמות להסבר הביטול.

בהשוואה שנצפתה, שתי דגימות רצופות הציבו את ה־Participant בדיוק ב־XY המבוקשים, עם שגיאת גובה18.850003ס״מ, ואת היעד בשגיאה0. זוהה ה־Guard המסוים כעוין עם קו ראייה, נצפה stack500 עץ ונשלחה בקשת Attack ציבורית אחת. זה מאמת את תיקון ההכנה במקרה הזה; אין צורך להוסיף משטח או לשנות חיישנים כדי להסביר את כשל130.

בכל40 דגימות חלון הפעולה הכלי המקורי נשאר מצויד וההורה שלו תאם למלאי הבנייה של ה־Participant. זה הבדל לעומת ניסויי Guard עם כלי שאול שנפרק בזמן התקיפה. סוג המתכון המסוים לא זוהה, ואין קביעה שזה קיר. העץ נשאר500, בריאות היעד5000, ספירת הגופים בנפח הקבוע1 ולא נוסף בו גוף. בקשת Attack לא החזירה תוצאה לפני ביטול המשימה בתום8 שניות; אין הצלחת API או דחיית API שנובעות מכך. גם40/40 ציוד תקין אינו בנייה.
