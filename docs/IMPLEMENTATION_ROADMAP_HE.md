# מפת שלבים להשלמת ProCoachLab

הוראת העבודה העדכנית גוברת על סדר הניסויים ההיסטורי: המשתמש הפעיל מטרה חדשה להשלמת W0–W7, ולאחר מכן דרש להימנע מכל בדיקות המשחק וניסויי המנוע עד להכנת המימוש המלא. ממשיכים כעת בכתיבת קוד, יצירת נכסים, חיבור רכיבי העורך וגימור. אין להפעיל את רשימות הניסויים הישנות או סשן קבלה אוטומטי בגלל סעיף W2 להלן. קומפילציה נדרשת לחיבור שדות חדשים היא עבודת פיתוח; אינה קבלת משחק, בנייה/עריכה או איכות חזותית. מצב המימוש הנוכחי נמצא בראש BUILD_STATE_HE.md.
